# 我的桌宠

面向 Windows 的桌面角色陪伴应用。支持静态立绘与 Live2D、对话驱动情绪和动作、独立聊天记录、任务提醒，以及可选的本地角色语音。

当前软件版本：**0.1.0 公开测试版（发布准备中）**。视频 v22d 是介绍视频的版本，与软件版本独立。

## 下载与开始使用

正式下载地址将在仓库与许可确认后补充。当前没有已发布的 Release，也没有网盘镜像链接。

1. 下载发布版 ZIP，解压后双击 `我的桌宠.exe`，选择安装位置和运行方式。
2. 静态立绘可自由新建和导入；Live2D 请导入官方签名角色包。角色包启动器会定位已安装的本体，已运行时请求切换角色。
3. 在模型设置中填写兼容 OpenAI Chat Completions 协议的对话接口参数，测试连接后保存。接口可能产生服务商费用；本项目不提供接口或密钥。
4. 如需角色语音，下载并启动可选本地语音环境，添加训练好的 GPT-SoVITS 权重和参考音频。语音计算在本机进行；对话和视觉请求仍会发送到你配置的服务商。

## 角色素材

本仓库和安装包不提供任何游戏角色、立绘、Live2D 模型、声音模型、参考音频或演示角色包。

静态角色建议使用透明背景全身 PNG。同一角色各图保持相同画布尺寸、比例和人物位置；推荐 2:3。局部显示直接从全身图截取，无需另备半身图。

```text
角色文件夹/待机.png                         # 单服装
角色文件夹/服装1/待机.png                   # 多服装
角色文件夹/服装1/动作1/待机.png             # 同服装多动作
```

图片按界面所列情绪命名；先查看常用情绪，再添加所需项目。

Live2D 仅加载通过内置公钥校验的官方签名角色包。包内资源保持不变；用户个性、情绪映射和语音参数单独存于本体数据目录。基础版不含 Live2D 组件，仍可使用立绘角色。详见 [角色包与签名](docs/CHARACTER_PACKAGES.md)。

## 语音与语言

角色包可包含已经配置好的 GPT-SoVITS 权重和参考音频，导入后按包内配置恢复；不包含整套语音运行环境。
自行添加声音时，需要训练或寻找有权使用的模型文件及对应参考音频、参考文本。先确认模型支持中文、日文或中日双语；不支持的语言效果可能不理想。可按语言调整参数；缺少中文参考音频时不能切换到中文。

## 运行环境

- 目标环境：Windows 10/11 x64；其他系统不在本次发布验收范围内。
- 基础桌宠不需要下载整套语音环境。
- 可选 GPT-SoVITS v2Pro 整合包约 8.2–8.9 GB，安装需至少 32 GiB 可用空间；下载与解压耗时取决于网络和磁盘。
- 有可用 CUDA 时使用 GPU，否则使用 CPU；CPU 合成可能较慢。不会安装显卡驱动或修改系统 Python。

## 从源码运行

使用带 Tcl/Tk 的 Python 3.11 x64：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config/app_config.example.json config/app_config.json
.venv\Scripts\python.exe main.py
```

可选 Live2D 依赖与构建说明见 [docs/BUILD.md](docs/BUILD.md)。角色、运行数据和本机配置不会提交到仓库。
