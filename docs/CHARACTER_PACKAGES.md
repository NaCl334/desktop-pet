# 角色包与签名（路线 B）

本体安装一次。静态立绘自由添加、导入；Live2D 仅加载通过本体内置 Ed25519 公钥验签的角色包。每次启动、切换和创建渲染器均重新校验，没有成功缓存。

## 使用者

解压完整 Live2D 角色包，双击“启动角色.exe”。启动器查找本体的顺序是：本机路径缓存 → 当前用户注册表 → 手动选择本体 EXE。路径缓存位于 LocalAppData/我的桌宠/launchers/<包路径摘要>/body_path.txt，注册表为 HKCU\Software\我的桌宠 的 InstallPath（完整 EXE 路径）。缓存不放入签名角色包，否则记录路径本身就会破坏签名。

移动本体后再次选择 EXE 即可。角色包首次使用会验签并复制到本体 characters/<id>；重复启动相同包不重复导入。同 ID、不同内容的包不会静默覆盖已有文件；请备份后在角色管理移除旧包，再导入新版。全局只运行一个桌宠；已运行时通过 WM_COPYDATA 请求现有实例切换。

Live2D 原始文件不能在编辑页直接覆盖。个性、情绪映射、服装选择、语音参数保存到 data/character_overrides/<id>，不改签名资源。单独指定的新语音权重及参考音频保留外部路径；移动或删除这些文件后需重新选择。导出签名包保持原始签名与资源，不打包本机覆盖设置。

缺少 Live2D 组件时会提示并回退静态角色；没有静态角色则进入首次配置。环境检测中的 Live2D 是可选项，不阻止仅桌宠模式。

## 包制作者（本地操作）

签名文件覆盖包内除 signature.ed25519 之外所有文件的路径、大小与 SHA256，包括启动器。先构建启动器，再准备完整资源，最后签名。模型配置必须为 .model3.json；表情为 .exp3.json，动作为 .motion3.json，可用中文或英文名称，引用必须位于包内。

```powershell
.\scripts\build_character_launcher.ps1 -PythonPath '<Python 路径>'
python scripts/prepare_signed_character_package.py '<原角色目录>' --output '<新目录>' --launcher '<启动器 EXE>' --key '<项目外私钥 PEM>' --zip
# 已准备好的完整目录也可单独签名
python scripts/sign_character_package.py '<角色包目录>' --key '<项目外私钥 PEM>'
```

私钥不进入仓库、角色包、日志或聊天。包签名之后增加、删除或修改任何文件都需要重新签名，包括 README 和启动器。模型/声音等素材的使用与分发权限需要另行取得，签名不代表素材授权。

公钥公开且内置于程序；开源程序可被修改，签名用于官方发行版的来源和完整性校验，不是不可绕过的 DRM。

请备份私钥。私钥丢失不会使已发布签名失效：已有本体仍能验证旧包，但无法继续使用同一密钥签发新包。更换密钥需要更新本体的信任公钥及后续包；私钥泄露则应视为发行身份被冒用，制定密钥更换与旧密钥撤销方案。
